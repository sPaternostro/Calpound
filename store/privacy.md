# Calpound — privacidad (para pegar en una URL pública)

Calpound guarda el perfil, las comidas, el movimiento y el banco solo en el dispositivo. No hay cuenta ni servidor propio.

La cámara se usa únicamente para leer códigos de barras. No se almacenan fotos.

Las búsquedas de productos se envían a Open Food Facts (base abierta). No enviamos tu nombre, peso ni historial.

Podés borrar todos los datos desde Ajustes.
